# Y — 창작소 최하층 추가 및 저층부 연결

콘타 포함 Rhino 8/mm. 창작소 하부에 Z35.75–39.75의 4m 층을 추가했다. 기존 Z39.75–43.75층도 두 작업동 사이를 채워 하나의 연속된 평면으로 연결했다. 하부 중복 도로 통로는 삭제했다. Z43.75 상부 진입은 유지하며, 연결된 하부 매스의 지붕이 통로 바닥 역할을 하므로 중복 슬래브는 제거했다.

우체국 및 창작소 Z43.75 이상은 유지. 메시 없는 박스 Extrusion 솔리드, 우체국 살구색/창작소 청회색, 별도 창 패널 레이어 유지. 원본 콘타 227개 객체 보존. 코어 없음.

## 모델 기준 면적

- 대지: 4,445.638453㎡ (원본 SITE 경계)
- 건축 투영면적: 2,102㎡ → 건폐율 47.2823%
- 모델 바닥면적: 6,260㎡ → 최하층 포함 용적률 140.8122%
- 신설 창작소 최하층: 1,204㎡
- 신설 최하층만 지하층으로 제외하는 시나리오: 5,056㎡ → 113.7294%

건축 투영면적은 층 매스와 지붕의 평면 합집합. 바닥면적은 프로그램 매스 및 지붕이 있는 공용 바닥의 레벨별 합집합이다. 외부 테라스·외부 계단·보이드는 제외하고 내부 계단 투영은 포함된 공공 홀 바닥과 중복 가산하지 않았다. 창 패널은 면적에서 제외했다. 경사지 지하층 판정 및 법정 산입/제외 규정을 확정한 법규 산정치는 아니다. 계산값은 Rhino 문서 사용자 텍스트에도 기록했다.

검증: 신규 Extrusion 유효·닫힘, 신규 메시 없음, 원본 콘타 보존, 상층/우체국 평면 유지, 연결된 저층부 및 신설층 평면 일치, 상부 접근 동선 연속성, 계단과 프로그램 매스 사이 간섭 확인.
