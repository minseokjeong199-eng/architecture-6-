# J안 — ㄴ자 우체국 + ㄱ자 창작소

새로 첨부된 「프로그램 조닝 계획.pdf」의 수정 방향을 반영한 Rhino 8 개념 매스입니다. I안의 아트리움과 계단을 유지하면서 프로그램의 평면·단면 관계를 바꿨습니다.

## 파일

- `J_interlocking_context.3dm`: 원본 지형·주변 건물 포함 통합 모델
- `J_interlocking_overlay.3dm`: 제안 매스만 포함. 원본과 동일 좌표·mm 단위
- `J_interlocking_cutaway.3dm`: 지붕과 동측 일부 실영역을 숨긴 내부 확인 모델
- `J_proposal_board.pdf/png`: 전체 매스와 층별 프로그램 평면
- `J_sections_A3_1-200.pdf/png`: 실제 형상 교차로 생성한 단면. PDF를 A3 100% 인쇄하면 단면 1:200, 하단 평면은 축척 없음
- `J_area_schedule.csv`, `J_area_audit.csv`: 층별 면적 및 가산 근거

## PDF 반영 사항

| 수정 방향 | 모델 반영 |
|---|---|
| 우체국이 ㄴ자 하부 기반 형성 | 남측 우체국에서 서측 날개를 아트리움 옆으로 연장 |
| 창작소가 ㄱ자로 감쌈 | 북측 창작소와 동측 날개를 연결, 상층 동측 부분을 우체국 위로 확장 |
| 평면뿐 아니라 단면에서 중첩 | Z35.75 우체국 실영역 위 Z39.75 창작소 실영역의 투영 중첩 111㎡ |
| 공공 로비와 제작 갤러리 연결 | 우체국 로비 발코니 21㎡, Z43.75 상층 갤러리 51㎡ 추가. 갤러리는 하층 공공 홀 위를 횡단 |
| 보이드 경계를 층마다 변화 | 중앙 일부 폭을 12m에서 16m로 확장하고 바닥 돌출·갤러리를 배치 |
| 기존 내부 길 발전 | 90° 방향전환 계단, 제작·교환·중고마켓 노드와 부분 개방 지붕 유지 |

층고는 4m이며 모델 레벨은 31.75 / 35.75 / 39.75 / 43.75m입니다. 레벨은 모델 좌표값으로 공인 해발고가 아닙니다. 상부 및 동측 도로 접점과 철도측 완충 공간을 유지했습니다. 마켓은 두 주 프로그램의 공유 공공 공간으로 포함됩니다. 물류 지원 240㎡ 표시를 유지했으며 별도 대형 물류 매스는 추가하지 않았습니다.

## 면적 검토

모델 SITE 경계 면적 4,445.638㎡를 사용합니다. 공식 지적면적은 미확정입니다.

- 건축 투영 2,401.425㎡ / 건폐율 **54.02%** (한도 60%)
- 기본 층별 바닥 8,255㎡ + 중복 제거한 추가 계단참 96㎡ + 진입부 32.425㎡ = **8,383.425㎡**
- 바닥 합계 / 대지면적 = **188.58%**
- 계단 수평투영 93㎡를 별도로 가산한 보수적 합계 **8,476.425㎡ / 190.67%** (한도 200%)
- 일부 매입층도 면적 공제 없이 산입했습니다. 법정 연면적·건축면적 확정 산정은 아닙니다.

실영역 합계는 우체국 약 3,431㎡, 창작소 약 3,543㎡이며 공유 바닥은 별도입니다. 로비·갤러리 등 공유 영역을 특정 프로그램 면적으로 중복 가산하지 않았습니다. 상하층 중첩 111㎡도 면적 추가 항목이 아닙니다.

## 모델 사용 및 검증

신규 레이어는 `우체국`, `창작소`, `공공동선_마켓`, `수직동선_구조`, `물류_지원`, `아트리움_지붕` 등의 이름이며 **Proposal 접두사가 없습니다**. 원본 레이어는 보존했습니다.

원본 227개 객체와 원본 파일 해시를 보존했습니다. 신규 객체 유효성·솔리드 여부·저장 후 재열기·실제 슬래브 면적과 계산 면적 일치·대지 내 투영·철도 완충 비침범을 검사했습니다. 원본 도로 Brep 중 기존 오류 2개는 원본 그대로 유지합니다.

개념 매스이므로 상세 벽체·문·피난계단 설계는 포함하지 않습니다. 상층 교차 갤러리의 전이보는 구조 위치 표시이며 구조 계산 결과가 아닙니다. 프로그램별 독립 운영·방화 구획·피난 유효폭·채광·접속부 경사는 후속 평면 설계에서 확인해야 합니다.
