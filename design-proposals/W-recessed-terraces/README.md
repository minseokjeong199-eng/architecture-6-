# W — 깊은 입면 후퇴와 연속된 테라스

Rhino 8 파일, mm. 원본 콘타 227개 객체 유지. 최신 참고 이미지의 살구색 창작소 / 청회색 우체국 / 중립색 아트리움으로 구성했다.

창작소 층 매스에 1.5~2.4m 깊이의 입면 후퇴를 실제로 파고, 전면 작업동을 중앙 방향으로 낮아지도록 연장했다. 상부는 세 개의 작은 매스로 분절했다. 우체국은 저층을 후퇴시키고 상층 외곽을 유지하며, 세 중정과 아트리움 측 노치를 뒀다. 중앙은 낮은 단차 지붕과 외피를 갖는 공공 홀이다.

복잡한 파임을 갖는 프로그램 매스는 층별·연결된 덩어리별 유효한 닫힌 메시다(NURBS 솔리드가 아님). 바닥/천장 객체로 분리하지 않았다. 공공 계단과 외피는 별도 객체이며 코어는 없다. 층고 4m, 도로 접점 Z43.75 / Z35.75 유지. 층별 메시 편집은 Rhino 메시 편집 명령을 사용한다.

이번에는 사용자 요청에 따라 용적률 목표에 맞추는 형상 조정을 하지 않았다. 단일 이미지의 공간적 해석이며 정확한 치수 복원이나 구조·법규·무장애 상세 설계가 아니다.

확인: 닫힌 메시/기존 Extrusion 유효성, SITE 내 배치, 원본 콘타 객체 보존, 계단과 프로그램 및 외피 사이 2.1m 상부 공간 간섭. 내부 형상 점검용 이미지는 산출물에 포함하지 않는다.
