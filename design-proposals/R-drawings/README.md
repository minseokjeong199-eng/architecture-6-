# R안 매스에서 추출한 DWG 도면

[DWG 다운로드](R_mass_drawings.dwg?raw=true)

원본: `R_reference_mass_only.3dm`. 저장된 Rhino Extrusion의 외곽과 내부 프로파일을 직접 읽어 추출했습니다. 우체국의 계단형 상부 외피도 실제 수직 프로파일을 절단했습니다.

## 구성 — 한 DWG의 모델 공간에 총 11개 뷰

- P-01~05: 기준 Z35.75 / 39.75 / 43.75 / 47.75 / 51.75m의 평면. 절단 높이는 각 기준 높이 +1.2m.
- P-06: 실제 상면의 가림 관계를 반영한 지붕·테라스 평면.
- S-01~03: A-A(U=-1m), B-B(U=12m), C-C(V=36m) 직교 단면. 위치는 평면에 표시.
- E-01~02: 앞쪽 및 오른쪽 매스 입면. 보이지 않는 뒷면은 제거한 외형 투영.

단위는 mm, 모델 공간 1:1입니다. 도면을 읽기 쉽게 건물 축에 맞춰 회전하고 3열로 옮겨 배치했습니다. 원본 지형 좌표에 그대로 중첩되는 파일은 아닙니다. 출력 배율·용지는 CAD에서 설정하십시오. 평면 치수는 전 층 건물 몸체의 전체 범위를 기준으로 하며 개별 층 면적을 뜻하지 않습니다.

파랑 POST / 빨강 LAB / 노랑 PUBLIC으로 분리했습니다. 상부 투영은 점선, 절단 및 레벨선은 별도 레이어입니다. 선은 편집 가능한 폴리라인이고 설명은 TEXT입니다. 치수 표시는 선과 글자로 구성되어 있으며 연관 치수 객체는 아닙니다.

## 적용 범위

이 도면은 **매스 검토용 평면·단면·입면**입니다. 벽 두께, 문·창, 실 구획, 구조, 설비, 코어를 새로 설계하지 않았습니다. 계단은 R안의 모델 형상을 투영한 것으로 법정 피난·무장애 계획을 확정한 도면이 아닙니다. L00~L04는 기하학적 기준 높이의 명칭이며 법적 지하/지상층 판정이 아닙니다.

R안의 8,200㎡ 목표는 미확정입니다. 이 도면으로 이전 Q/P 면적표를 확인한 것으로 간주하면 안 됩니다. 원본 지형에서 연속 단면을 확인하지 못했으므로 임의의 지반선을 추가하지 않았습니다.

## 파일 검증

실제 DWG R2000(AC1015)로 변환했습니다. DWG를 다시 DXF로 읽어 608개 모델 공간 객체의 좌표·텍스트·레이어, mm 단위, 색상·선종류·선굵기가 유지됨을 확인했습니다. 재읽기 후 DXF 감사 오류는 0개입니다. AutoCAD 프로그램에서 직접 열어 시험한 것은 아닙니다.
