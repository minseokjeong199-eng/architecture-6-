# Y안 층별 단선 구획 DWG

사용자 첨부 Drawing1.dwg와 최신 `Y_connected_lower_storeys_context.3dm`을 기준으로 작성했다. 원본 파일은 변경하지 않았다. 결과물은 실제 DWG(AC1015)이며 mm, 모델 공간 1:1이다. 모델 공간에 3열로 레벨별 평면을 배열했다. 각 레벨 레이어를 독립적으로 편집할 수 있다. 해치 및 채움 없음.

## 포함 도면

- L0 Z35.75 — B1 가칭, 서비스·지원
- L1 Z39.75 — 1F 가칭, 공공서비스·교환
- L2 Z43.75 — 2F 가칭, 상부 도로 진입·교육·업무
- L3 Z47.75 — 3F 가칭, 창작·갤러리
- L4 Z51.75 — 4F 가칭, 입주 작업실
- L5 Z55.75 — 모델에 있는 상부 스튜디오를 누락 없이 별도 도면화
- M Z41.75 — 아트리움 중간참, 독립된 전체 층이 아님

각 주요 레벨에 실 구획, 계단실, 승강기, 남녀 화장실, 공용/장애인 WC, EPS·PS·TPS 및 청소 지원 공간을 배치했다. 상층은 작은 매스에 맞춰 공용 WC와 코어를 유지한다. 해당 매스가 없는 층에 코어를 추가하지 않았다. 레벨별 동일 코드의 코어·설비 공간은 동일 XY 위치다. 아트리움 중간참은 아래층의 코어를 공유한다. 실 출입은 D 마커, 코어 출입은 문호로 표현한다. 계단 단수 표시는 4m 층고/24단 개념이며 실시설계 계단 상세가 아니다.

## 도면 기준

Drawing1은 기존 실내 평면이 아닌 대지·주변 건물·출입 주석 도면이다. 공통 경계점 17개를 회전·이동만으로 정합했으며 최대 정합 오차는 0.000001mm 미만이다. 단위 변경 및 비균등 스케일을 하지 않았다. 3D SITE는 4,445.64㎡, 첨부 DWG SITE는 4,593.91㎡로 도로 접점 일부가 다르다. 실선 SITE_3D를 설계 기준으로, 첨부 경계를 SITE_DWG_REF 점선으로 남겼다. 첨부 도면의 출입/하역/지하주차 주석은 참고 정보로 표시했으며 해당 시설을 새로 설계했다는 뜻은 아니다.

첫 도면은 Rhino 원래 XY 좌표다. 후속 도면 이동량은 plan_audit.json에 기록했다. 외곽은 Y안 실제 3DM Extrusion에서 추출하고 메타데이터 면적과 대조했다. 코어/화장실/실별 용도와 구획은 새로 제안한 2D 계획이며 3D 매스를 변경하지 않았다. 기존 지붕·테라스는 점선으로 참조하고 내부 색면이나 해치는 없다.

## 검증 범위

신규 코어 전부 해당 층 매스 안에 포함, 코어 상호 중복 없음, 수직 정렬 확인. DWG 변환 후 다시 DXF로 읽어 모델 공간 2,160개 객체의 좌표·레이어·한글 문자를 원본과 대조했다(수치 허용차 0.0001mm). 해치 0개, 재독해 audit 오류 0개. LibreDWG로 재독해할 때 빈 Model_Space ENDBLK 경고가 있으나 모델 공간 객체 비교는 전부 통과했다. AutoCAD 자체 실행 검증은 하지 않았다.

이 파일은 검토용 구획 계획이다. 경사지 지상/지하 판정, 피난 거리·출구 수·계단 유효폭, 장애인 편의 상세, 위생기구 수, 구조 및 수직 설비 배관 용량은 확정하지 않았다. 층명은 도식용 가칭이며 Z값이 모델 기준이다.
