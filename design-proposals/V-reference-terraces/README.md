# V — 첨부 이미지의 형태를 따르는 테라스 매스

콘타 포함 Rhino 8 파일(mm). 원본 콘타 227개 객체 보존. 우체국 붉은 갈색, 창작소 파랑. 코어 제외.

창작소는 엇갈린 테라스, 두 작은 옥상 매스, 외부 테라스 계단으로 구성한다. 우체국은 후퇴한 저층 위에 동일한 외곽선의 연속된 상층을 놓고 세 개의 중정을 비웠다. 중앙은 낮게 단차진 유리 지붕과 측면 외피로 닫힌 아트리움이다. 지정된 출입구만 열고 도로 계단·테라스는 외부에 둔다.

층고 4m, 기존 상부 도로 진입 Z43.75m / 하부 Z35.75m 유지. 이미지의 형태를 해석한 개념 모델로, 원본 이미지의 정확한 치수 복원이나 지상 8200㎡ 면적 목표 충족을 의미하지 않는다. 구조·피난·무장애 상세는 미설계.

신규 솔리드 유효성, 대지 내 배치, 원본 콘타 보존, 계단과 실내 매스 및 외피 사이 2.1m 높이 간섭을 검사했다. 렌더링/도면/엑셀 산출물 없음.
