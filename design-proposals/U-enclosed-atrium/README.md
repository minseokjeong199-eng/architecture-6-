# U — 내부 아트리움과 프로그램 경계

Rhino 8, mm. 기존 contour.3dm의 227개 원본 객체를 그대로 포함한다.
우체국은 붉은 갈색, 창작소는 파랑이다. 코어는 포함하지 않는다.

창작소를 두 작업동과 상층 연결동으로 정리했다. 중앙 홀은 실내 프로그램 두 켜, 북·남측 유리 외피와 연속된 지붕으로 감싼다. 출입구를 제외한 측면은 막고, 도로 계단과 상부 테라스는 외부에 둔다. 우체국 상층에 Exchange 로비를 비우고 하부 도로 진입에는 후퇴한 로비를 둔다. 유리 외피 레이어를 숨기면 내부 홀과 계단을 확인할 수 있다.

층고 4m, 상부 진입 Z43.75m, 하부 진입 Z35.75m 유지. 컨셉 외피와 출입구는 표현했으나 문짝, 구조, 피난 및 무장애 상세 설계는 하지 않았다. 지상 8,200㎡ 목표와 면적 비율을 충족시킨 최종 설계가 아니며 건폐율·용적률 적합성을 인증하지 않는다.

검증: 신규 솔리드 유효성, 원본 콘타 보존, 대지 경계 내 배치, 계단과 실내 매스·외피 사이 2.1m 상부 공간 간섭 검사. 지붕과 측면 프로그램 상부의 겹친 면 제거. 내부 저해상도 형상 확인만 수행하고 이미지 산출물은 제공하지 않는다.
