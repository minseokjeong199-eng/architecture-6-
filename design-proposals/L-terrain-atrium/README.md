# L안 — 낮은 우체국 기반, 상층 창작소, 도로에서 시작하는 절개

첨부된 「프로그램 조닝 계획.pdf」를 반영했습니다. 지상 프로그램 합계 8,200㎡와 지하층 별도 조건, K안에서 올린 바닥 레벨, 층고 4m를 유지했습니다.

**추가 요청 반영:** 주 프로그램은 각 층의 프로그램 영역별 단일 솔리드입니다. 바닥판·천장·층 매스를 겹쳐 만들지 않았습니다. 중정 구멍도 솔리드 내부 프로파일로 처리하여 불필요한 삼각형 조각으로 분해하지 않았습니다. 떨어진 영역은 각각의 솔리드입니다. 열린 공공동선의 바닥, 계단, 램프, 코어와 차양은 공간 관계를 확인할 수 있도록 별도입니다.

## 파일

- `L_terrain_atrium_context.3dm`: 원본 지형·도로·주변 건물을 포함한 통합 모델
- `L_terrain_atrium_overlay.3dm`: 제안만 포함, 원본 좌표계 / mm 단위
- `L_terrain_atrium_cutaway.3dm`: 4층 매스·차양 및 동측 일부를 숨긴 내부 검토용 모델. 객체 삭제가 아니므로 다시 표시 가능
- `L_proposal_board.pdf/png`: 입체도·층별 프로그램 배치
- `L_section_study.pdf/png`: 실제 모델 형상과 교차한 두 단면. 축척 없음
- `L_area_schedule.csv`: 층별 프로그램 면적과 지하·계단 가산 구분

레이어는 `1F_우체국`, `2F_창작소`, `3F_공유동선` 등의 층별 이름이며 Proposal 접두사가 없습니다. 원본 컨텍스트 레이어는 보존했습니다.

지상 실제 바닥 합계 **8,107㎡**에 기존 공공계단 수평투영 **93㎡**를 보수적으로 별도 가산하여 **8,200㎡**입니다. 공유 1,700㎡는 순수 마켓·교육실뿐 아니라 공용동선과 계단 가산을 포함합니다. 경사 진입로는 평면 투영 75㎡로 2층 공유 면적에 포함했으며 중복 가산하지 않았습니다. 지하 2,189㎡와 하부 도로 진입참 5.133㎡는 별도입니다.

모델 SITE 면적 **4,445.638㎡** 기준, 재계산한 건축 투영 **2,579.133㎡**, 건폐율 **58.01%**입니다. 지상 8,200㎡를 이용한 용적률 검토값은 **184.45%**입니다. K안의 건폐율 54.02%를 복사하지 않고 변경 후 평면 합집합으로 계산했습니다. 지하층 인정은 이전 사용자 제공 조건이며 법정 면적 판정은 별도입니다.

## 도로 접속과 후속 검토

상부 도로의 모델 높이 **Z43.75**에서 **폭 5m·길이 15m·기울기 1:20**의 램프를 통해 **2F Z43.00**으로 연결합니다. 램프 양끝 높이는 모델에 직접 반영했습니다. K안 전체를 다시 이동한 것이 아니라, 올려 둔 기준 바닥 레벨을 유지하면서 진입부를 조정했습니다.

하부 도로 **Z35.75**는 새 진입참과 승강기 코어를 통해 **1F Z39.00**에 연결하는 개념입니다. 실제 출입문·승강기 승강장·방화구획·피난 상세는 설계하지 않았습니다. 중앙 16m 연결 매스의 장스팬 구조, 돌출부 지지, 테라스 난간, 램프 참과 손잡이, 채광·배수는 후속 검토 대상입니다. 이 파일은 층별 개념 매스이며 상세 건축도면이 아닙니다.
