# A안 — 길이 되는 마켓

우체국의 이동과 업사이클 창작소의 생산 사이에, 교환하며 통과하는 공공의 길을 만든다.

붙여주신 대화의 최종 조건인 **“CREATIVE & SECOND-HAND MARKET이 POST OFFICE와 UPCYCLE LAB을 연결하는 길”**을 기준으로 제안한 검토용 매스다. 원본 `contour.3dm`의 좌표에 직접 배치했다.

## 배치와 프로그램

| 구성 | 배치·매스 | 프로그램 관계 |
|---|---|---|
| POST OFFICE | 도면 아래쪽, 2층의 낮은 매스 | 우편·택배 서비스와 포장·물류를 1층, 관리·업무를 상부에 배치하는 가정 |
| MARKET STREET | 두 매스 사이의 폭 6m 길, 교환마당, 짧은 캐노피, 공개 제작 앞마당 | 길을 따라 판매·교환·전시가 생기며, 행사가 없는 날에도 통행 가능하도록 계획 |
| UPCYCLE LAB | 도면 위쪽, 높은 제작층 위에 상부층을 단계적으로 후퇴시킨 2~3층 매스 | 하부는 재료·제작, 상부는 교육·워크숍과 창작자 공간으로 나누는 가정 |
| 수직 연결 | 창작소 옆 공공 계단·승강기와 상부 테라스 | 낮은 마켓과 높은 쪽 도로 진입을 연결 |
| 재료 운반 | 우체국에서 창작소 측면으로 이어지는 별도 점선 경로 | 대지 내부의 카트 이동 구상. 차량 주행로를 뜻하지 않음 |

마켓 길의 기본 폭은 6m이며, 판매대를 운영할 때도 연속된 유효 통행 폭 약 3m를 남기는 운영을 제안한다. 중앙에서는 교환마당으로 넓어지고, 창작소 앞에서는 제작을 보여주는 전시·체험 영역이 된다. 마켓은 고정 상점의 집합보다 프로그램 두 개가 관계를 맺는 공용공간에 가깝다.

## 매스 형성 과정

1. 낮은 쪽·높은 쪽의 진입 후보와 기존 지형을 읽는다.
2. 우체국과 창작소를 떨어뜨려 놓고 사이에 공공의 길이 들어갈 공간을 확보한다.
3. 길을 마켓으로 확장한다. 우체국 문턱 → 교환마당 → 공개 제작 앞마당으로 이어진다.
4. 창작소의 상부를 후퇴시켜 테라스를 만들고, 계단·승강기로 높은 쪽 진입과 연결한다. 재료 운반은 길의 옆면으로 배치한다.

## 이번 모델의 높이·규모 가정

- 주 마켓 바닥: **모델 Z=34.5m**. 원본 SITE 객체의 넓은 상판 높이를 기준으로 잡았다.
- 창작소 상부 진입: **모델 Z=40.5m**. 두 마켓 레벨의 차이 6m를 계단·승강기로 연결한다.
- 우체국: 바닥 Z=34.5 / 39.0m, 지붕 Z=42.6m. 층별 매스 바닥면적 합계 **약 702㎡**.
- 창작소: 바닥 Z=34.5 / 40.5 / 44.7m, 최고 지붕 Z=48.3m. 층별 매스 바닥면적 합계 **약 810㎡**.
- 두 프로그램의 면적 합계는 약 1,512㎡이며, 마켓·테라스·외부동선 등은 별도다. 이는 **법정 연면적이나 확정 프로그램 면적이 아니다.**
- 원본 SITE의 주요 상판 경계 투영면적은 약 4,446㎡이다. 이 값은 작은 측면 단을 제외한 모델 형상 계산값이며, 지적 대지면적을 뜻하지 않는다.
- 도면 위쪽 진입 후보 주변 Road 객체는 Z 약 40~41m, 아래쪽 후보는 Z 약 33~34m다. 이는 주변 모델 객체에서 읽은 값으로 측량된 도로 접속고가 아니다.
- X·Y·Z는 원본 모델 좌표이며 Z를 해발고도로 해석하지 않았다. 배치도의 위쪽은 +Y이고 **실제 북향은 확인되지 않았다.**

## Rhino에서 열기

- **A_market_street_context.3dm**: 기존 지형·건물·도로와 제안 매스가 함께 있는 Rhino 8 파일. 먼저 이 파일을 열어 전체 관계를 확인하면 된다.
- **A_market_street_overlay.3dm**: 제안 매스와 SITE 상판 경계만 포함. 기존 모델에 Import하면 원래 좌표에 들어온다. 단위는 mm이며 축척 변경 없이 불러온다.
- `PROPOSAL_A_POST`, `LAB`, `MARKET`, `CANOPY`, `CORE`, `SERVICE`, `SITE`, `LABEL` 레이어로 구분했다. 레이어 이름은 모두 `PROPOSAL_A_`로 시작한다.
- 컨텍스트 파일에서는 기존 빨간 SITE 솔리드를 보존하되 초기 표시만 껐다. 빨간 경계는 `PROPOSAL_A_SITE`에 표시했다. 기존 SITE를 비교하려면 해당 레이어를 켜면 된다.
- 필요하면 `PROPOSAL_A_LABEL`을 끄고, 새 매스 레이어의 객체를 선택한 뒤 Zoom Selected로 확대한다.
- 원본 `/workspace/architecture-6-/contour.3dm`은 변경하지 않았다.

## 확인한 것과 다음 설계에서 확인할 것

새로 생성한 객체의 형상 유효성, 매스 솔리드의 닫힘, 파일 재읽기, 기존 객체 ID 보존, 원본 파일 해시 보존을 검사했다. 새 바닥 형상의 꼭짓점과 변 위 표본점들이 주요 SITE 상판 경계 안에 있는지도 확인했다. Rhino 데스크톱에서의 화면 확인은 수행하지 않았다.

도로와 대지의 실제 접속, 하역 차량의 진입·회차, 지형과 기초·옹벽, 법규상 이격·피난·무장애 동선, 일조와 방위, 목표 연면적은 후속 설계 대상이다. 진입 표시와 내부 물류 점선은 후보 경로이며 접속이 확정되었다는 뜻은 아니다. 기존 모델을 정밀 절토하거나 지반·기초를 설계한 것은 아니다.

이번 파일은 프로그램과 높이 관계를 검토하기 위한 매스이며, 겹치는 바닥·코어는 공간을 표시하는 모델링 요소다. 벽·문·방화구획·구조·승강기 상세는 포함하지 않았다. 제작실의 소음·분진은 공개 제작 공간과 구획하면서 시각적 연결을 유지하는 방향으로 다음 평면에서 다룬다.

원본 Road 레이어의 Brep 2개에 이미 있던 형상 유효성 오류는 그대로 보존되어 있다. 제안 매스의 오류와 구분해야 한다.
