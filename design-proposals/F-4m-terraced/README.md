# F안 — 층고 4m, 두 건물과 계단식 테라스

참고 이미지의 상층 후퇴, 옥상 테라스, 중앙 마당·계단·연결길을 두 주 건물에 적용했습니다. 우체국과 창작소가 주 매스이며, 공유 마켓은 각 건물의 2층 내부에 300㎡씩 포함합니다. 중앙에 별도 마켓 건물은 만들지 않았습니다. 식재 화단·옥상 가장자리·작은 테라스 차양을 개념 형상으로 포함했으며 이미지의 창호·루버·가구·수목을 정밀 복원한 모델은 아닙니다.

## 높이

두 건물 모두 4층이며 모든 실제 층고는 정확히 4m입니다.

| 구분 | 모델 Z(m) |
|---|---:|
| 기존 주요 지표 | 34.50 |
| 1층 | 35.75 |
| 2층 / 측면 도로·공유 길 접속 | 39.75 |
| 3층 / 높은 도로 접속 | 43.75 |
| 4층 | 47.75 |
| 지붕 | 51.75 |

기존 도로 접속층을 유지하면서 층고를 4m로 통일하기 위해 1층 바닥을 지표보다 1.25m 높였습니다. 이 부분은 실내층이 아닌 기단입니다. 도로측 1층 진입계단·참과 지상까지 내려오는 개념 승강기 코어를 넣었으며, 실제 승강기 출입구·무장애 동선·하역 도크의 상세 설계는 후속 검토입니다. 층고 4m는 실내 유효 천장고 4m라는 뜻은 아닙니다.

## 면적

| 건물 | 1층 | 2층 | 3층 | 4층 | 합계 |
|---|---:|---:|---:|---:|---:|
| 우체국 | 1,164 | 1,164 | 976 | 576 | **3,880㎡** |
| 창작소 | 1,002 | 1,002 | 870 | 660 | **3,534㎡** |

실내 합계 7,414㎡. 공유 마켓 600㎡는 이 면적에 이미 포함됩니다. 우체국 물류 240㎡도 내부에 포함되며 도로측으로 모았습니다. 우체국은 크리틱 전 계획 2,000㎡보다 확대하고 창작소는 기존 약 3,500㎡ 규모를 유지했습니다. 공유 마켓을 제외한 우체국 기능 면적은 3,580㎡입니다.

연결길·외부 계단·문턱까지 포함한 보수적 검토 연면적은 7,588.29㎡입니다. 모델 대지 4,445.64㎡ 기준 건폐율 **51.7%**, 용적률 **170.7%**로 제시 상한 60%/200% 이내입니다. 테라스 위 외부계단도 추가 산입하여 법정 산정과 구분됩니다. 건축 투영면적은 2,296.29㎡입니다. 공식 대지면적·실제 면적 산정 규정·높이 제한은 미확정입니다.

프로그램 운영 방향은 E안 스터디를 유지하되 층별 면적은 이 F안 표로 대체합니다. E안의 세부 실별 배분은 F안의 확정 평면이 아닙니다. 물류 240㎡는 운영 물량 검증 전 계획값입니다.

## 파일

Rhino 8, mm 단위, 원본 좌표 유지. `context`는 주변 지형·건물 포함, `overlay`는 제안 객체만 포함합니다. `PROPOSAL_F_POST`, `LAB`가 주 매스, `MARKET`은 연결길·계단·내부 조닝, `BUFFER`는 조경 화단입니다. 내부 조닝 객체는 기본 숨김이며 `Show`로 확인할 수 있습니다. `CORE`, `ROAD`는 기본 숨김 레이어입니다.

새 객체 유효성·닫힌 솔리드, 모든 층고 4m, 저장 후 재열기, 주요 대지 내 배치와 철도 완충 비중첩을 확인했습니다. 원본 파일은 변경하지 않았고 기존 도로 Brep 2개의 결함은 보존했습니다. 계단·난간·차양은 개념 형상이며 구조·피난·방수 상세 검증 전입니다.
