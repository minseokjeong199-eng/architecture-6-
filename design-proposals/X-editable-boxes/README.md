# X — 수정 가능한 박스 솔리드

콘타 포함 Rhino 8 파일, mm. 신규 프로그램 매스는 메시가 아닌 직사각형 Extrusion 솔리드다. W안의 층별 평면 외곽과 높이를 유지하면서 파인 입면을 제거했다. 중정과 아트리움, 층별 돌출·후퇴는 박스 사이의 배치로 유지한다. 바닥·천장 객체로 나누지 않는다.

우체국은 살구색 RGB 224,157,119, 창작소는 청회색 RGB 124,153,173으로 교환했다. 객체/레이어/재질 색상을 함께 변경했다.

두 건물의 창은 구멍 대신 얇은 별도 솔리드 패널이다. `우체국_창표현_별도패널`과 `창작소_창표현_별도패널` 레이어를 숨기거나 편집할 수 있다. 창은 입면 표시용이며 실제 창호 상세는 아니다. 층 매스는 `우체국_Z…`, `창작소_Z…` 레이어, 각 박스는 BOX 번호로 식별한다.

원본 콘타 227개 객체 보존, 신규 메시 없음, 모든 신규 Extrusion 유효/닫힌 솔리드 확인. W안과 프로그램별·층별 평면 합집합 일치 확인. 층고와 도로 접점 유지. 코어 없음. 용적률 조정은 수행하지 않았다.
