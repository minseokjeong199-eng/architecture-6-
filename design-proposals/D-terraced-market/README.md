# D안 — 참고 이미지 기반 계단식 매스

[전체 ZIP](D_terraced_market_package.zip?raw=true) · [주변 포함 Rhino 3DM](D_terraced_market_context.3dm?raw=true) · [제안 매스만 Rhino 3DM](D_terraced_market_overlay.3dm?raw=true) · [보드 PDF](D_proposal_board.pdf?raw=true)

![D안](D_proposal_board.png)

사용자가 제공한 참고 이미지의 큰 하부 건물, 두 개의 중정, 계단식 상부 건물과 중앙 공공 계단을 원본 대지에 맞춘 개념 매스입니다. 이미지의 정확한 치수 복원이나 상세 건축 모델이 아닌 형태·높이 관계의 제안입니다.

- 우체국: 2층의 큰 직교형 매스 안에 두 개의 열린 중정.
- 창작소: 높은 도로에 붙는 3층 건물과 점차 낮아지는 작업실·옥상 테라스.
- 창작마켓: 도로측 2층 건물과 양쪽 저층 실내 판매 공간. 중앙에는 넓은 계단과 마당을 배치.
- 측면 도로에서 Z39.75 마켓층으로 접속하고, 높은 도로에서 Z43.75 창작소층으로 진입. 철도측에는 완충 공간을 유지하며 출입구를 만들지 않음.

모델 대지면적 4,445.64㎡ 기준, 외부 계단·데크까지 포함한 보수적 검토값은 건축 투영면적 2,292.88㎡(51.6%), 층·외부 동선 면적 합계 4,256.88㎡(95.8%)입니다. 제시된 60%/200% 이내이며 공식 지적 면적 및 법정 산정이 확정된 값은 아닙니다. 외부 데크의 겹치는 부분은 연면적 검토에서 중복 공제하지 않았습니다.

Rhino 8, mm 단위, 원본 좌표 유지. `PROPOSAL_D_*` 레이어에서 프로그램별 편집이 가능합니다. `context`는 주변 지형·건물 포함, `overlay`는 제안 객체만 포함합니다. 원본 SITE 솔리드는 주변 포함 파일에서 숨김 처리했습니다. 내부 코어는 위치 검토용 숨김 레이어입니다.

생성 솔리드의 유효성·닫힘, 파일 저장 후 재열기, 주요 대지 안의 배치, 철도 완충 공간과의 비중첩을 확인했습니다. 원본 contour.3dm은 변경하지 않았으며 기존 도로 Brep 2개의 결함은 보존되어 있습니다.

식재는 단순 화단 매스이며 수목·사람·차량·가구·유리·입면 루버는 포함하지 않았습니다. 계단은 높이 관계를 보여주는 개념 형상으로, 휴식참·난간·피난·무장애 동선 및 토목·구조 상세 검토 전입니다. 도로·철도 방향은 기존 사용자 확인을 우선했습니다.
