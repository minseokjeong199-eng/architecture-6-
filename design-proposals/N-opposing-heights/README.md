# N안 — 양쪽의 높이 방향을 반대로 조정한 매스

사용자 스케치의 왼쪽은 철도, 오른쪽은 도로로 해석했다. 철도 측은 도면 아래쪽으로, 도로 측은 위쪽으로 높은 부분을 배치했다. 기존 M안의 공공 가로와 중앙 반외부 공간은 유지했다.

## 이번 수정

- 코어 솔리드와 해당 레이어를 삭제했다. 공공 계단과 경사로는 유지했다. 피난·승강기 계획은 이번 매스 파일에 포함하지 않는다.
- 3층 철도 측 위쪽 112㎡를 아래쪽으로 옮겼다. 4층은 철도 측 아래쪽 450㎡, 도로 측 위쪽 688㎡로 분리하여 총면적 1,138㎡를 유지했다. 두 높은 부분 사이를 열린 중앙 공간으로 남겼다.
- 우체국 상부 295㎡를 4층 철도 측으로 배치하고 3층 우체국은 355㎡로 조정했다. 지상 프로그램 총량은 그대로다.
- 상부 진입 끝점은 기존 모델의 도로 기준 Z43.75m에 일치하며, 15m 길이의 1:20 경사로로 Z43m 층에 연결한다. 하부 진입 바닥과 우체국 진입홀은 Z35.75m에 일치한다. 기존 지형·도로는 이동하지 않았다. 연속 도로 측량 자료가 없어 모든 경계 구간의 접속까지 확인한 것은 아니다.
- 일반 층고 4m, 층 바닥 Z39 / 43 / 47 / 51m, 최상부 Z55m. 기존 +3,250mm 이동값을 유지했으며 다시 가산하지 않았다.
- 우체국 갈색, 창작소 파랑. Proposal 접두사 없음. 층별 프로그램 솔리드를 유지하며 바닥·천장 중복 매스를 추가하지 않았다. 공유 바닥·계단·경사로는 구분되어 있다.

대지 모델 면적 4,445.64㎡ 기준 건폐율 59.63%, 지하 제외 면적비 184.45%. 지하 2,209㎡와 외부 진입참 5.13㎡는 별도다. 지하까지 모두 산입하면 234.26%이므로 지하층 법적 인정 여부에 따라 용적률 판단이 달라진다. 지하층 분류는 사용자가 제시한 계획 전제이며 법적 확정값이 아니다.

중앙 바닥 324㎡ 중 연속 모임 바닥 150㎡, 상부 매스 아래 144㎡, 하늘에 열린 부분 180㎡. 모임 바닥은 중앙 바닥의 부분집합이며 중복 가산하지 않는다.

## 파일

- `N_public_street_context.3dm`: 기존 지형·주변과 제안을 함께 포함한 Rhino 8 / mm 모델. 기본 파일.
- `N_public_street_overlay.3dm`: 같은 원점의 제안만 포함. 원본과 결합할 때 사용.
- `N_public_street_cutaway.3dm`: 상부 일부가 숨겨진 내부 확인용 모델.
- `N_mass_preview.png`: 실제 수정 모델로 만든 조감도. 비용 절감을 위해 단일 시점만 제작했다.
- `N_height_diagram.pdf/png`: 사용자 스케치 방향에 맞춘 높이 설명도.
- `N_area_schedule.csv`: 층별 면적표.
- `N_validation.json`: 저장된 Rhino 솔리드 면적, 원본 보존, 계단 상부 여유 확인 결과.

기존 M안의 이미지·단면을 이번 수정 결과로 혼용하지 않는다. 이 파일은 개념 매스이며 구조·피난 상세를 확정한 도면이 아니다.
