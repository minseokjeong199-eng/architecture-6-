# K안 — 면적 비율 수정 및 매스 상승

사용자가 확인한 **지상층 목표 합계 8,200㎡, 지하층 별도** 기준을 적용했습니다. 지상층은 우체국 4,000㎡ / 마켓·교육 및 공용동선 1,700㎡ / 창작소 2,500㎡입니다.

## 변경

- 제안 건축 전체를 **Z +3,250mm** 이동. 원본 지형·건물·도로 및 철도측 지상 완충은 고정.
- 기존 최하층을 사용자 제공 조건에 따라 **B1**으로 분류하고 용적률 검토에서 제외.
- 층고 **4m**의 상부층을 추가하여 B1 + 지상 4층 구성.
- 우체국 ㄴ자와 창작소 ㄱ자 관계를 유지하면서 프로그램 경계와 최상층 규모를 재조정.
- 상층 추가에 맞춰 아트리움 지붕 및 수직 코어를 연장. 공유 마켓·교육은 두 프로그램의 내부 길과 갤러리로 배치.
- 신규 레이어 이름은 Proposal 접두사 없이 유지.

## 면적 — 중복 없는 기준

| 지상 프로그램 | 면적 | 지상 합계 대비 |
|---|---:|---:|
| 우체국 | 4,000㎡ | 48.78% |
| 마켓·교육 및 공용동선 | 1,700㎡ | 20.73% |
| 창작소 | 2,500㎡ | 30.49% |
| 지상 합계 | 8,200㎡ | 100% |
| 지하 별도 | 2,189㎡ | 지상 비율에서 제외 |

공유 1,700㎡는 활동영역과 공용동선, 추가 계단참 96㎡, 진입부 32.425㎡, 계단 수평투영 보수적 가산 93㎡를 포함합니다. 1,700㎡ 전체가 순수 전용 마켓·교육실 면적이라는 뜻은 아닙니다. 우체국·창작소는 매스 내부 영역 기준이며 벽체·전용 코어를 상세 공제한 순면적이 아닙니다. 구체 실별 프로그램은 후속 평면 작업 대상입니다.

지상 실제 바닥 합계 8,107㎡ + 계단 수평투영 가산 93㎡ = 8,200㎡. 지하 포함 실제 바닥 합계 10,296㎡, 계단 가산 포함 검토 합계 10,389㎡입니다.

모델 대지 4,445.638㎡ 기준 건폐율 **54.02%**, 지상 8,200㎡를 이용한 용적률 검토값 **184.45%**입니다. 이미지의 대지 4,500㎡를 사용하면 182.22%입니다. 지하층 법정 인정은 사용자가 제공한 조건을 적용했으며 별도 법규 판정을 수행하지 않았습니다.

## 수정 후 바닥 레벨

| 층 | 모델 Z (m) |
|---|---:|
| B1 | 35.00 |
| 1F | 39.00 |
| 2F | 43.00 |
| 3F | 47.00 |
| 4F | 51.00 |

이 값은 모델 좌표이며 공인 해발고가 아닙니다. 원본 도로를 고정한 채 건축을 이동했으므로 **이전 도로 접속의 같은 높이 조건은 더 이상 검증된 상태가 아닙니다**. 새 진입 레벨과 도로를 연결하는 계단·경사로 상세 조정은 별도입니다. 지하 판정이 이동 전/후 어디에 적용되는지도 공식 단면에서 확인해야 합니다.

## 파일

- `K_rebalanced_context.3dm`: 지형·주변 건물 포함
- `K_rebalanced_overlay.3dm`: 제안만 포함, 원본 좌표계 / mm
- `K_rebalanced_cutaway.3dm`: 지붕과 동측 일부를 숨긴 내부 검토용
- `K_proposal_board.pdf/png`: 층별 평면·입체도·비율
- `K_program_schedule.csv`: 지하 및 지상 층별 면적, 공용 가산 내역

실제 슬래브 면적과 표의 일치, 지상 프로그램 합계, 신규 형상 유효성, 저장 후 재열기, 신규 레이어 이름을 검사했습니다. 원본 컨텍스트는 변경하지 않았습니다. 최상층 일부는 하부층보다 돌출되므로 구조 전이와 피난·무장애 동선의 상세 설계가 필요합니다. 이번 파일은 개념 매스입니다.
