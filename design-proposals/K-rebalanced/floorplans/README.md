# K안 층별 평면도 — B1 / 1F / 2F / 3F / 4F

현재 K안의 매스와 바닥 형상을 그대로 추출했습니다. 이번 작업에서 매스·면적·높이는 변경하지 않았습니다.

## 열기

- **K_all_floorplans.dwg**: 다섯 층을 가로로 나란히 배치한 통합 도면. 모델 공간에서 Zoom Extents로 전체 보기.
- **K_B1_plan.dwg ~ K_4F_plan.dwg**: 층별 개별 도면.
- 같은 이름의 **DXF**: 호환용 원본 벡터 도면.
- **K_floorplans_A3_1-250.pdf**: A3 세로 5페이지. 100% 실제 크기 출력 시 1:250.
- **K_floor_areas.csv**: 층별 바닥 합집합 면적. 기존 K안의 추가 계단참과 진입부를 각 층에 포함하여 계산.

DWG/DXF는 **mm 단위, 모델 공간 1:1, 평면 Z=0**입니다. 층의 실제 높이는 제목에 표시했습니다. 도면을 읽기 쉽게 건물 기준축으로 회전·평행이동했으므로 원본 Rhino 세계좌표와 직접 겹쳐지지 않습니다. 실제 북향 표시는 아닙니다. 개별 도면들은 같은 평면 좌표를 사용하고, 통합 도면은 각 층을 X방향 65,000mm씩 이동했습니다.

## 레이어

`B1_POST`, `1F_PUBLIC`, `2F_LAB`처럼 층 + 기능으로 구분했습니다. Proposal 접두사는 없습니다.

| 끝 이름 | 내용 |
|---|---|
| POST | 우체국 바닥·프로그램 경계 |
| LAB | 창작소 바닥·프로그램 경계 |
| PUBLIC | 공유 마켓·교육·공용 바닥, 계단참, 진입부 |
| SLAB | 층별 바닥 외곽 |
| CORE | 현재 모델의 수직 코어 투영 |
| STAIR | 해당 층으로 들어오거나 나가는 기존 계단의 수평투영 |
| ACTIVITY | 기존 활동영역 |
| FURNITURE | 기존 전시대·작업대 |
| SITE | 대지경계 참고선 |
| TEXT | 층·레벨·면적·전체 폭·스케일 바 |

글꼴 호환을 위해 CAD 내부 주석과 레이어는 영문으로 작성했습니다. 도면은 편집 가능한 폴리선과 텍스트입니다.

## 면적과 도면의 의미

지상 실제 바닥 합계는 **8,107㎡**, 여기에 계단 수평투영 검토 가산 **93㎡**를 더한 기존 K안의 지상 계획 합계는 **8,200㎡**입니다. 지하 **2,189㎡**는 별도입니다. CSV의 층별 공유 면적에는 이미 추가 계단참·진입부가 포함되므로 기존 표의 추가참·진입부를 다시 더하지 않습니다.

이 도면은 **매스에서 추출한 프로그램 평면도**입니다. 프로그램 선은 벽체 시공선이 아니며, 새 실 구획·벽 두께·문·화장실·피난계단 상세를 임의로 만들지 않았습니다. 계단은 기존 모델의 투영이므로 아래층과 위층 계단을 함께 표시하는 층이 있습니다. 4F에는 기존 모델에 없는 계단 디테일을 새로 넣지 않았으며 코어 영역만 표시합니다. 면적은 코어를 중복 가산하지 않은 기존 매스 기준입니다.

DWG는 AutoCAD 2000 계열 형식으로 저장했습니다. 변환 후 다시 DXF로 읽어 모델 공간 객체 수, 레이어, 폴리선 좌표 및 텍스트의 일치를 확인했습니다. 통합 도면 263개 객체, 개별 도면 B1 23개 / 1F 54개 / 2F 92개 / 3F 64개 / 4F 30개입니다. AutoCAD 프로그램 자체에서의 열기 검사는 수행하지 않았습니다.
