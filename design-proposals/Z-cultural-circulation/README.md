# Z — 문화창작순환플랫폼 단선 평면 발전안

결과물 `Z_cultural_circulation_plans.dwg`는 실제 DWG(AC1015), mm, 모델 공간 1:1이다. 주요 레벨 6개와 Z41.75 아트리움 중간참, 설계판단 설명을 3열로 배열했다. 해치 없이 단선 구획이며 프로그램/출입/코어/공공동선/물류동선/차량 레이어를 분리했다.

## Y안에서 변경

- B1 Z35.75의 중앙을 채워 창작소–공용 지원–우체국이 연결된 한 평면으로 구성했다. 원래의 대지와 상층 창작소 형상은 유지한다.
- 우체국의 세 소형 중정과 아트리움 측 상층 노치를 폐쇄했다. 1F 교환 허브와 연결되는 실내 로비 절개는 유지했다. 중정의 채광·환기 기능을 무시한 것은 아니며 상주 기능은 외곽, 내부는 보안/문서/지원 기능 위주로 배치하고 환경 성능은 다음 단계에서 검토한다.
- 중앙 아트리움은 넓은 공공 계단과 승강기로 이동한다. 에스컬레이터는 채택하지 않았다. 교환·수선·창작품 판매·카페와 교육/제작 관찰 갤러리를 두어 활동을 보며 올라가는 순서를 만든다.
- 도로측 공공 EV 전실을 B1 물류와 분리했다. 우체국 방문→교환/포장→마켓/카페→계단→교육/공개제작의 공공 흐름을 별도 레이어로 표시했다. 중간참은 계단 관람용 보조전시이며 별도 전체 층/참여 프로그램이 아니다.
- B1은 하역·입고검수–다기능작업–집배/특수계/발송대기와 재료 분류–재료용 리프트를 연결한다. 공공 EV, 직원 EV, 업무용/재료용 리프트를 구분했다. 물류 이동은 관리문을 통과한다.
- 집배실, 특수계·보안 작업, 발착/소포계 사무실, 현업실, 금고/현금관리, 갱의·휴게·샤워, 설비 및 카페 비품 지원을 계획에 반영했다. 화장실/EPS/PS/TPS와 계단의 수직 정렬은 유지한다.
- 원도에서 철도측에 표시된 물류 주석은 현 진입으로 채택하지 않았다. 차량은 도로측 접점으로 가정한다. 하역차 6.5×2.5m 1대, 집배 밴 5.2×2.0m 2대, 이륜차 4대를 검토 가정으로 표시했다. 회차 원형선은 공간 확보 표시이며 실차 조향 궤적 검증이 아니다.

## 첨부 자료의 적용

사용자 제공 **『(2013)우정사업건축』, 우정사업조달사무소**, 재첨부 `(2013)우정사업건축1.pdf` 136쪽에서 관련 부분을 검토했다. 원문 전체나 페이지 이미지는 저장소에 재배포하지 않는다.

- PDF p.10, 서울금천우체국(한기/선진): 우편물류·위탁소포·집배 이륜차·고객 동선의 구분, 고객/현업실–다기능작업장–집배실 연결, 직원과 고객 분리, 직원 휴게 인접.
- PDF p.18, 서울금천우체국(이가/J&J): 물류 코어/직원 코어 분리, 집배실 및 작업실의 채광·환기, 먼지 발생 작업의 외기 면 배치, 개별 중정의 환경적 역할.
- PDF p.24, 김포우체국 사례: 고객/직원/물류 차량 분리, 다기능작업장과 우편마당, 이륜차의 안전한 진입.
- PDF pp.30–31, 김포우체국(성림): 고객실·현업실·다기능작업장·집배실·이륜차 주차 연계. 특수계, 휴게/갱의, 물류 사무실, 기계/전기 등 실 구성.

이 사례들의 차량 수·시설 규모를 그대로 복사하지 않고 동선과 필수 지원 기능을 이 프로젝트의 검토 규모에 맞춰 적용했다. 문화창작 부분의 공간 구성과 카페·공공 계단 판단은 본 프로젝트의 설계 제안이다. 인터넷 사례를 읽었다고 주장하지 않는다.

## 모델 기준 면적 검토

대지 4,445.64㎡, 지하층을 제외한 건축 투영면적 2,240㎡ → **건폐율 약 50.4%**. 지상으로 가정한 층들의 바닥 합계 4,952㎡ → **용적률 약 111.4%**. B1 전체 2,268㎡까지 포함한 모델 바닥 총합은 7,220㎡(162.4%)다. Y안에서 신설 창작소층만 제외했던 시나리오와 달리 여기서는 B1 전체를 제외한 값을 표시한다. 경사지 지하층 판정 및 법정 면적 공제 확정치가 아니다.

## 기준과 검증

외곽 검증용 Z안 매스는 Y안에서 지하 연결·우체국 중정 폐쇄·2F 갤러리를 반영해 생성했다. 새 코어·실 구획은 2D 계획이며 이 단계에서 모든 코어를 3D로 모델링한 것은 아니다. Drawing1.dwg의 공통 경계점 17개 정합을 유지하며 SITE 실선은 3D 기준, 점선은 원 DWG 참고 경계다.

B1 전체가 하나의 연결된 무보이드 평면인지, 우체국 중정 폐쇄, 코어가 매스 내부에 있는지, 층간 정렬과 코어 간 중복이 없는지 검사했다. DWG 변환 후 재독해하여 모델 공간 2,506개 객체의 좌표·레이어·한글 문자를 원 DXF와 비교했다(수치 허용차 0.0001mm). 해치 0개, 재독해 audit 오류 0개. 빈 Model_Space ENDBLK 경고는 있으나 모델 공간 비교는 전부 통과했다. AutoCAD 자체 실행 검증은 하지 않았다.

운영 인원·업무량, 차량 톤수·접안 높이·도로 경사·구조 및 방재/피난·무장애 상세·환기/집진·설비 용량은 아직 확정하지 않았다. 실 출입 D 표시는 위치 제안, 코어 문호는 개념 개구부다. 실시설계 도면이 아니다.
